# Cool Cat — Daily Load Report

Interactive prototype of a daily exceptions report for the Agg Loads admin:
loads not yet invoiced, loads with no picture, and loads with no weight, with
filters for driver, customer, site, vehicle, category, tip location and more.

Mock data only. Single page in `public/index.html`, served by a zero-dependency
Node server (`server.js`) for Railway.

```bash
npm start
```

Then open http://localhost:3000.
